How Encryption Key Rotation Works

This system demonstrates a secure, automated IoT cryptographic lifecycle. When an authorized physical button on the ESP32 is pressed, the device securely signals AWS IoT Core without exposing any secret keys.

1. ESP32 Trigger

The push button on GPIO 0 triggers a signed JSON rotation request published over TLS to esp32/key_rotation/request.

2. AWS IoT Core

IoT Core validates the device X.509 certificate and routes the message via an IoT SQL Topic Rule to AWS Lambda.

3. AWS Lambda

The serverless function verifies the request and securely calls the AWS KMS API kms:RotateKeyOnDemand.

4. AWS KMS

AWS KMS rotates the cryptographic backing material within FIPS 140-2 Level 3 HSMs. The KMS Key ID remains unchanged.

5. OLED Confirmation

Lambda publishes the new version confirmation back to esp32/key_rotation/response and the ESP32 OLED updates.
